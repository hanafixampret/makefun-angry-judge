Entry for the make.fun bounty [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046): a program that writes one short, funny rant to `/output/entry.txt`.

The rant: "I bought one apple. The self-checkout screamed 'unexpected item in the bagging area' like I'd smuggled a grand piano. I lifted the apple. I put it down. I apologised to a machine. The attendant watched all of it and said, 'Yeah, it does that.' Then why is there a camera judging me?"
